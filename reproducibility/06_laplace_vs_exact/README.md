# 06_laplace_vs_exact: accuracy of the Laplace approximation

This folder reproduces Appendix F of the paper and its Table 1. The chain
of LEWIS with the Laplace approximation (L) is compared with the exact
chain (E). In the exact chain, the Laplace approximation of each node is
replaced by an unbiased importance sampling estimate of its marginal
likelihood (a pseudo-marginal chain). The stationary distribution of the
exact chain is the exact posterior.

## Design

* Data: the ER graphs of the comparative study with rho = 0.5 and s = 1,
  and the 13 pairs (p, n) of Table 1. The datasets are generated with the
  regime tag `"mixture"`, so they are the datasets of the comparative
  study where the pairs (p, n) agree.
* 100 datasets for each pair (p, n).
* Both chains start at the estimate of the TL method and run for the same
  number of iterations, `lewis_schedule(p)`: 10,000 for p <= 20, 62,500
  for p = 50 and 250,000 for p = 100.
* Both priors: the complexity prior with alpha = 0.75 and d = 0.03, and
  the uniform prior.
* The exact chain uses 300 importance draws per node for p <= 20 and 150
  for p >= 50.
* For each chain, the highest-scoring DAG is compared with the true DAG
  through the SHD between their CPDAGs. The post-processing is not used.

## Table 1

The columns "SHD (L)" and "SHD (E)" are the mean SHD over the 100
datasets. The column "Time ratio" is the mean computing time of the exact
chain divided by the mean computing time of the Laplace chain, over the
100 datasets of each pair (p, n) and each prior. It is a ratio of mean
computing times, not a mean of ratios.

## Files

| File | Purpose |
| --- | --- |
| `laplace_vs_exact.R` | Runs both chains on every dataset and writes `results/exact_vs_laplace.csv`. |
| `make_table_lve.R` | Checks the per-dataset file and writes the two summary files and the body of Table 1. |
| `results/exact_vs_laplace_summary.csv` | Mean and standard deviation of the SHD and of the computing time for each (p, n, prior, chain). |
| `results/exact_vs_laplace_runtime_ratio.csv` | Mean computing times of the two chains and their ratio for each (p, n, prior). |
| `../common/laplace_exact.R` | The start graph, the Laplace chain, the exact chain and the CPDAG SHD. |
| `../common/laplace_exact.cpp` | The exact chain and the importance sampling estimate in C++. |

The two summary files in `results/` are those of the paper. The file with
one row per dataset, `exact_vs_laplace.csv`, is in the Zenodo archive (see
`../ZENODO.md`).

The Laplace chain uses the sampler of the package LEWIS through its
unexported function `LEWIS:::lewis_mcmc_cpp()`, because Appendix F needs
the highest-scoring DAG of the chain, which `lewis()` does not return. The
exact chain is compiled with `Rcpp::sourceCpp()` when the script starts.
The machine that runs it needs a C++ compiler (as for installing the
package) and the R packages `Rcpp` and `quantreg`. The compiled code is
cached in the folder given by the environment variable `LEWIS_EXACT_CACHE`,
or in a temporary folder.

## Inputs

None. The datasets are generated by `../common/scenario_instances.R`.

## Run order and commands

The scripts find their own folder, so they can be started from any folder.
The commands below start from the root of the repository (the folder that
contains `reproducibility/`).

1. Computation. With SLURM:

   ```sh
   mkdir -p reproducibility/slurm/logs
   sbatch reproducibility/slurm/laplace_vs_exact.slurm
   ```

   Without SLURM:

   ```sh
   MC_CORES=100 Rscript reproducibility/06_laplace_vs_exact/laplace_vs_exact.R
   ```

   The datasets of one pair (p, n) run in parallel on `MC_CORES` cores of
   one machine. Without `MC_CORES`, all cores but one are used. The script
   writes the results file after each pair (p, n). A run that is
   interrupted can be started again. It skips the datasets that are
   complete in the file. The script exits with status 1 and lists the
   failed datasets if a dataset fails.

2. Table, on a laptop:

   ```sh
   Rscript reproducibility/06_laplace_vs_exact/make_table_lve.R
   ```

   It writes `results/exact_vs_laplace_summary.csv`,
   `results/exact_vs_laplace_runtime_ratio.csv` and
   `<figure folder>/laplace_vs_exact/table_lve_body.tex`, and prints the
   rows of Table 1. The first row is
   `10 & 100 & 6.64 & 6.64 & 19.0 & 6.52 & 6.61 & 20.9 \\`. The figure
   folder is the value of the environment variable `LEWIS_FIG_DIR`, or
   `reproducibility/figures/` if it is not set.

To rebuild the table without running the chains, copy
`exact_vs_laplace.csv` from the Zenodo archive to `results/` and run
step 2.

## A quick check on one dataset

This check runs the two chains under the uniform prior on dataset 1 of
p = 10 and n = 100. It takes a few seconds. Start R in
`reproducibility/06_laplace_vs_exact/` and run:

```r
# Load the package and the shared code.
library(LEWIS)
COMMON_DIR <- "../common"
source("../common/settings.R")
source("../common/scenario_instances.R")
source("../common/graph_tools.R")
source("../common/laplace_exact.R")
load_exact_engine()
# The dataset and the start graph.
view <- instance_view(build_instance("ER", 10), rho = 0.5, effect_scale = 1)
X <- draw_dataset(view, n = 100, rep = 1, regime_tag = "mixture")
start <- tl_start_dag(X)
# The two chains, in the order of laplace_vs_exact.R.
n_iter <- lewis_schedule(10)$n_iter
lap <- laplace_chain(X, start, "uniform", n_iter)
ex <- exact_chain(X, start, "uniform", n_iter, M = 300)
edge_string(lap$dag)
edge_string(ex$dag)
```

The two edge lists of the paper are
`1>5;1>8;6>8;8>5;9>2;9>6;9>8;10>2;10>6` (Laplace chain) and
`1>5;5>6;8>1;8>5;9>2;9>6;10>2;10>6` (exact chain).

## Run time and hardware

The runs of the paper used a cluster node with 100 cores and 128 GB of
memory. The whole study took about 55 core-hours, or about one hour on the
node. The four chains of one dataset take about 16 minutes at p = 100 and
n = 1000, and less than one minute for p <= 20. The table script takes a
few seconds. The computing times, and hence the time ratios, depend on the
machine. The SHD values do not.
